# EduNote

A simple Flutter note-taking app for keeping class notes in one uncluttered
place. Notes can be assigned to built-in subjects or subjects you create, then
filtered or searched when you need them.

## Run the app

Install the Flutter SDK, then from the project directory run:

```shell
flutter pub get
flutter run
```

Notes and subjects are saved locally on the device.

## Run tests

```shell
flutter test
```
